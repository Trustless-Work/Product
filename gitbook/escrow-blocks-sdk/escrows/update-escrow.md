# Update Escrow

## Single Release

### Installation

Execute this command to add the code component.

{% tabs %}
{% tab title="npm" %}
```sh
npx trustless-work add escrows/single-release/update-escrow/form
// or
npx trustless-work add escrows/single-release/update-escrow/dialog
```
