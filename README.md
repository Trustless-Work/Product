# Trustless Work Spikes

## Supported Claim Types

| Claim Type | Description | Chain |
|---|---|---|
| **ACTA** | Proof of humanity attestations | Solana |
| **Identity** | Human verification via OKR | Any EVM |
| **Social Score** | Social reputation score | Any EVM |
| **OKR** | Objective Key Results tracking | Any EVM |
| **Escrow Attestation (ACTA)** | Escrow-based attestations on ACTA protocol | Base |

## Getting Started

Each claim type has its own processor that validates and executes claims according to the specific requirements of the underlying protocol.
